# ZyneLabs Kali Learn 🐉

Learn **Kali Linux** and **NetHunter tools** with English-Myanmar guides, flashcards,
quizzes and a practice terminal — built for Burmese speakers, up to Pro level.

## 📱 Get it

Download `KaliLearn-1.4.apk` from [Releases](../../releases) and install on Android.

## ✨ Features

- **104 lessons** in 13 categories: Kali basics, information gathering, vulnerability
  analysis, web app testing, password attacks, wireless testing, exploitation,
  post-exploitation, forensics, NetHunter, NetHunter install guides, anonymity & OPSEC,
  practice labs
- Each lesson: tool/command + **English explanation** + **Myanmar explanation** + ethics note
- 📖 **Tap any lesson** for the full detail page — examples, common options, "Try in Terminal"
- 🛠️ **Tools tab** — 28 major Kali tools (Nmap, Metasploit, Burp Suite, Wireshark,
  Aircrack-ng, …) with long-form chapter-style guides
- 📲 **NetHunter install guides** — root, TWRP, installer, KeX, WiFi adapters, troubleshooting
- 💻 **Terminal** — safe simulated Kali shell with command history
- 🃏 **Flashcards** · ✅ **Quiz** · 🔍 **Search** · ⭐ **Favorites**

> ⚠️ For education only — practice on your own systems, home lab, or CTF platforms.

## 🛠️ Android source

Built with a manual no-Gradle pipeline (`kotlinc` + `aapt2` + `d8`).
